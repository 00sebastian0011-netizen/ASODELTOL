# Registro de decisiones arquitectónicas

Las ADR capturan decisiones duraderas, alternativas y consecuencias. Numeración secuencial, título corto y estados `Propuesta`, `Aceptada`, `Rechazada` o `Sustituida`.

Una ADR aceptada no se reescribe para cambiar la historia. Una decisión posterior crea otra ADR y marca la anterior como sustituida.
